# MULTI-OTO ユーザーマニュアル

**バージョン 1.1.0** / Windows (64bit) / VST3・Standalone
開発: OTODESK ([@kijyoumusic](https://x.com/kijyoumusic))

---

## 1. はじめに

MULTI-OTO は、最大 **128 個のマルチバンド・コンプレッション・ノードを直列にカスケード接続**できるダイナミクス／サチュレーション・プラグインです。

表面的には ADAA（反導関数アンチエイリアシング）サチュレーションを備えたマルチバンド・アップワード／ダウンワード・コンプレッサーですが、本質は**サウンドデザインツール**です。

- **8 個くらいまで** — 一般的な OTT の使い方。音に迫力を出す、明るくする、密度を上げる。
- **16 個以上** — アーティファクトやノイズそのものを狙う領域。**音が暴れることを許容した設計**です。

ミックスやマスターの仕上げ用ではなく、音を作り変えるための道具だと考えてください。

---

## 2. シグナルフロー

```
入力
 → Pre-Drive (ADAA サチュレーション + DC ブロッカー)
 → [ クロスオーバー → アップワード/ダウンワード・コンプ → 再合成 ] × (2〜128 カスケード)
 → ポストフィルター (HPF / LPF)
 → Dry/Wet ブレンド
 → マスターリミッター (LIMIT / CLIP)
 → 出力
```

カスケードは前半を **STAGE 1**、後半を **STAGE 2** が担当します。COUNT が 64 ならノード 1〜32 が Stage 1、33〜64 が Stage 2 です。各ステージ内の全ノードには同一の設定が適用されます。

## 3. 画面構成

### ヘッダー

| 項目 | 説明 |
|---|---|
| **RANDOM** | メイン画面を音楽的にランダマイズ |
| **MOD** | LFO モジュレーション・マトリクス |
| **CONFIG** | 表示テーマとリミッターの詳細設定 |
| **PRESET** | プリセットブラウザ |

現在読み込んでいるプリセット名がボタンの左に表示されます。

### 上段: DYNAMICS METER

Stage 1 / Stage 2 のリアルタイム表示です。バンド幅はクロスオーバー周波数に連動して対数スケールで変化します。

**マウス操作**

| 操作 | 効果 |
|---|---|
| バンドの**上半分**を上下ドラッグ | UPWARD 量 |
| バンドの**下半分**を上下ドラッグ | DOWNWARD 量 |
| Shift または Alt + ドラッグ | BAND GAIN |
| ダブルクリック | GAIN を 0 dB へリセット |
| **バンド境界**を左右ドラッグ（↔ カーソル） | クロスオーバー周波数 |
| Alt + ドラッグ | 微調整（感度 1/6） |

### 中段: PRE-DRIVE / MASTER

| コントロール | 範囲 | 説明 |
|---|---|---|
| **PRE-DRIVE** (ボタン) | ON/OFF | サチュレーション・ブロックの有効/無効。ON 時は 17kHz LPF も同時に入ります |
| **IN** | -24 〜 +24 dB | 入力ゲイン |
| **DRIVE** | 0 〜 100 | ADAA サチュレーターへの入力量 |
| **ODD** | 0 〜 100 | 奇数次倍音。矩形波寄りの硬いエッジ |
| **EVEN** | 0 〜 100 | 偶数次倍音。非対称で真空管的な太さ |
| **HPF** | 20 〜 1000 Hz | カスケード後のハイパス |
| **LPF** | 1k 〜 20k Hz | カスケード後のローパス |
| **DRY/WET** | 0 〜 100 % | 原音とのブレンド |
| **OUT** | -24 〜 +24 dB | 出力ゲイン |
| **CEILING** | -2.0 〜 -0.1 dB | リミッターの天井 |
| **OTT xN** | 2〜128 | カスケード総数。プラグインの心臓部 |
| **PHASE MODE** | COLOR / ALIGN | 後述 |

### 下段: STAGE 1 / STAGE 2

2 つのステージを左右に同時表示します。各ステージは **3 行（LOW / MID / HIGH）× 5 列（GAIN / UP / DN / ATK / REL）** の行列です。

| コントロール | 範囲 | 説明 |
|---|---|---|
| **ON** | ON/OFF | そのステージ全体をバイパス |
| **TIME** | 10 〜 1000 % | ステージ内の全 Attack / Release への乗数。低いほど速い |
| **MIX** | 0 〜 100 % | ノードごとのパラレル処理量（Xfer OTT の "Depth" 相当） |
| **LOW X** | 20 〜 1000 Hz | LOW / MID の分割点 |
| **HIGH X** | 1k 〜 20k Hz | MID / HIGH の分割点 |
| **LINK** (Stage 2) | ON/OFF | ON にすると Stage 1 の LOW X / HIGH X を動かしたとき Stage 2 も一緒に動きます。編集の補助機能で、音そのものには影響しません |
| **GAIN** | -24 〜 +24 dB | バンドごとのメイクアップゲイン |
| **UP** | 0 〜 100 % | アップワード・コンプの量 |
| **DN** | 0 〜 100 % | ダウンワード・コンプの量 |
| **ATK** | 0.1 〜 100 ms | アタックタイム |
| **REL** | 1 〜 1000 ms | リリースタイム |

> **v1.1.0 の重要な変更**
> Stage 1 と Stage 2 のクロスオーバーは **完全に独立** しました。2 段で異なる帯域分割をぶつけると、片方の境界がもう片方のバンドの内側に落ちるため、帯域の重なりから複雑な位相干渉と共鳴が生まれます。これが本機を「ただの直列 OTT」から引き離す最大の要素です。

## 4. 効き方のしくみ

### GAIN は段数分だけ累乗される

帯域ゲインは**各ノードで**適用されるため、カスケード全体では `GAIN × 段数` になります。

| 段数 | 1 段あたりの目安 | 合計 |
|---|---|---|
| x2 | +8 dB | +16 dB |
| x8 | +3 dB | +24 dB |
| x32 | +1.4 dB | +45 dB |
| x128 | +0.5 dB | +64 dB |

128 段で +8 dB を設定すると合計 +1024 dB となり、float の表現範囲（約 +770 dB）を超えます。段数を上げたら GAIN は必ず下げてください。ファクトリープリセットはこの比率に沿って作られています。

### アップワード・コンプが尾を作る

閾値 -40 dB 以下の弱い信号を最大 +36 dB まで持ち上げます。128 段を通ると、音が止まったあとの微細な残響やノイズフロアが段階的に増幅され、「シュワーーー」という長いテールになります。これが MULTI-OTO の象徴的な音です。

REL をバンドごとにずらす（例: REL H を 40ms、REL L を 250ms）と、テールが周波数方向にスイープします。

### PHASE MODE

DRY/WET を 100 % 未満にしたときだけ意味を持つスイッチです。

- **COLOR PHASE** — DRY は素通し。WET だけがクロスオーバーで位相が回っています。混ぜると位相差で打ち消し合いが起き、**櫛形（コムフィルタ）の色が付きます**。DRY/WET ノブが「音量ブレンド」ではなく「位相キャンセルによる音色ノブ」に化けます。
- **ALIGN PHASE** — DRY 側にも同じ位相回転だけを掛けます（分割して圧縮せずに足し戻す）。位相が揃うので打ち消しが起きず、DRY/WET が**素直な音量ブレンド**として機能します。原音の芯を残しつつ効果量だけ調整したいときに使ってください。

DRY/WET が 100 % のときは、両モードは完全に同一の音になります。

## 5. CONFIG

### COLOR THEME

GUI の配色を 10 種類から選べます。音には一切影響しません。背景だけでなく、**ノブのアクセント色とメーターのバンド色も丸ごと切り替わります**。

`Midnight` / `Sakura` / `Ocean` / `Forest` / `Sunset` / `Mono` / `Neon` / `Amber` / `Ice` / `Vapor`

Mono ではバンド固有色もグレースケールになります。テーマの選択はプリセットには保存されず、常にあなたの好みが維持されます。

### LIMITER

| 項目 | 説明 |
|---|---|
| **LIMIT** | ピークエンベロープを追従して滑らかに抑えます。RELEASE で戻りの速さを調整 |
| **CLIP** | シーリングで即座に折り返します。倍音は増えますが密度が上がります |
| **CEILING** | -2.0 〜 -0.1 dB |
| **RELEASE** | 1 〜 500 ms（LIMIT モードのみ有効） |

どちらのモードでも、**出力が CEILING を超えることはありません**。128 段のアップワード・コンプレッションは膨大なゲインを生むため、モニターの音量には十分注意してください。

## 6. MOD MATRIX

ヘッダーの **MOD** ボタンで開きます。本機のパラメータを LFO などで自動的に動かす仕組みです。

### ソース

| ソース | 説明 |
|---|---|
| **LFO 1〜4** | 独立した低周波発振器。両極性（−1 〜 +1） |
| **Env Follow** | **入力音量そのもの**。片極性（0 〜 1）。叩いた瞬間だけ帯域が動く、といった使い方ができます |
| **Drift** | 階段状に飛ばない**連続的なランダム**。約 1 秒ごとに新しい目標値を引き、時定数 0.4 秒で滑らかに寄っていきます。両極性 |

本機はエフェクトなので MIDI ノートを受けません。Velocity や Note の代わりに **Env Follow** が入っています。

### LFO

| 項目 | 説明 |
|---|---|
| **波形** | Sine / Triangle / Saw / Square / S&H / Chaos / **Rnd Trig** |
| **SYNC** | ON でホストのテンポに同期。OFF なら Hz 指定 |
| **RATE** | 0.01 〜 30 Hz（0.01 Hz = 約 100 秒周期）。低速側が細かく触れるようスキューしてあります |
| **同期音価** | 1/1 〜 1/32（付点・3連含む 13 種） |

**Chaos** は基本波と √2 倍の周波数を重ねた非整数比の波で、決して同じ形を繰り返しません。

**Rnd Trig** は 1 周期ごとに **50 % の確率でだけ**値を更新します。周期は一定でも「動く / 動かない」が不規則になるので、ステップシーケンサがつっかえたような挙動になります。グリッチを作るときはこれが一番強力です。

#### ランダム系 3 つの違い

紛らわしいので整理します。すべて「でたらめな値」ですが、**動き方**がまったく違います。

| | 動き | 周期 | 使いどころ |
|---|---|---|---|
| LFO の **S&H** | 階段状にカクッと飛ぶ | 一定（RATE で指定、SYNC 可） | 拍に合わせて値をランダムに切り替える |
| LFO の **Rnd Trig** | 階段状に飛ぶが、**半分は飛ばない** | 一定だが発生が不規則 | つっかえ・抜けのあるグリッチ |
| ソースの **Drift** | **飛ばない。連続的に漂う** | 周期なし（約 1 秒ごとに向きが変わる） | 手で少しずつ動かしているような、生っぽい揺らぎ |

S&H と Rnd Trig は LFO の RATE に従うので**テンポに同期できます**。Drift は同期という概念がなく、ただゆっくり漂い続けます。

右端のバーは LFO の現在値をリアルタイム表示します。中央が 0、左右が ± です。

### マトリクス（8 スロット）

各スロットは `SOURCE → DESTINATION` を `AMOUNT`（−100 〜 +100 %）で結びます。

- **POL (UNI)** — OFF なら両側（−〜+）に振れ、ON なら片側（0〜+）だけに振れます。ベース値を中心に揺らしたいときは OFF、ベース値から一方向にだけ動かしたいときは ON。
- 同じ行き先に複数スロットを割り当てると**加算**されます。

### アサイン先

行き先は全 30 個。数が多いので、**STAGE 1 / STAGE 2 / LFO RATE に分類されたツリーメニュー**から選びます。DST 欄をクリックすると開きます。

| 行き先 | 変調の効き方 |
|---|---|
| S1 / S2 **Time** | ±2 オクターブ（1/4 倍 〜 4 倍） |
| S1 / S2 **Low X / High X** | ±2 オクターブ |
| S1 / S2 **Mix** | ±50 % |
| 各バンドの **Gain**（6 個） | ±24 dB（GAIN ノブの可動範囲そのもの） |
| 各バンドの **Atk / Rel**（12 個） | ±3 オクターブ（1/8 倍 〜 8 倍） |
| **LFO 1〜4 Rate** | ±15 Hz |

周波数と時間を「加算」ではなく**指数変化**にしているのは、88 Hz に ±500 Hz を足すと下側が潰れてしまうためです。±2 オクターブなら 22 Hz 〜 352 Hz と上下対称に振れます。

**帯域ゲインは段数で割りません。** 以前のバージョンでは「ゲインは各ノードで適用されるから効果は段数に比例するはず」と考えて、変調深さを段数で割っていました。理屈上はカスケード合計が一定になるはずでしたが、実際に鳴らすと x2 以外はほとんど変化が感じられませんでした。

理由は**ノードとノードの間にコンプレッサーが挟まっている**ことです。あるノードで持ち上げた分は、次のノードのダウンワード側が即座に引き戻します。ゲインは段数分そのまま積み上がらないので、「カスケード合計 dB」という指標が体感と一致していませんでした。

体感に効くのは **1 段あたりの深さそのもの**です。そこで現在は、段数にかかわらず常に **±24 dB**（GAIN ノブの可動範囲と同じ）を掛けています。x2 のときの効き方が x128 でもそのまま得られます。

安全面では、1 段あたりの上限は GAIN ノブを手で振り切ったときと同じ ±24 dB にクランプされます。さらに各ノードが入力を +120 dBFS でクランプするため、段数を重ねても Inf や NaN には到達しません。最終段のリミッターが CEILING を保証します。**段数が多いほど激しく暴れますが、それは設計どおり**です。大人しくしたいときは AMT を下げてください。

変調量が小さいと現在位置マーカーがノブのハンドルとほぼ同じ場所に来ます。マーカーはハンドルより後に、背景色の縁取り付きで描いているので、重なっても必ず見えます。帯が細くなりすぎる場合は表示幅に下限（約 10 px）を設けており、そのときはマーカーも「表示上の帯の中での位置」に読み替えて動かします（真の角度のままだと 1px も動かず止まって見えるため）。

**メーター側にも反映されます。** ゲインを変調すると、DYNAMICS METER のバンドに薄い緑の帯が重なります。これが「そのバンドのゲインがどこまで振れるか」の範囲で、実際のバーがその中を動きます。**Low X / High X を変調した場合はバンドの境界そのものが左右に動きます**（ヘッダーの周波数表示も追従します）。どちらもノブと同じ `applyModToValue()` を通しているので、見えている位置と実際に鳴っている帯域は一致します。

**LFO Rate を別の LFO で変調できる**のがこのマトリクスの肝です。周期そのものが不規則に伸び縮みするので、単純な周期性から抜け出せます。自分自身の Rate を自分で変調することもできます（1 ブロック遅延で安全に成立するよう作ってあります）。

### 変調レンジの表示

行き先に指定されたノブは、**リングの一部が色を変えます**。その区間が「今の設定でどこからどこまで振れるか」の範囲で、リングを横切る**明るい線**が現在の変調位置です。TIME / MIX / LOW X / HIGH X のバーでは、帯が背景に、現在位置が縦線として表示されます。

この帯は `ModMatrix::applyModToValue()` で実際の DSP と同じ計算式を通しているので、**表示された幅と実際に鳴る変調量は一致します**（帯が 10 px 未満になる極小の設定のときだけ、視認性のため下限幅が効きます）。

変調はブロックレート（バッファごと）で計算されます。ノブ自体は動きません（ベース値は保たれたまま、DSP へ渡す直前で変調が加算されます）。これは一般的なシンセの作法と同じで、変調中でも手でベース値を編集できます。

### MOD はプリセットで消えない

MOD マトリクスと表示テーマは「音色」ではなく**作業環境**として扱われます。プリセットを切り替えても INIT を押しても、組んだモジュレーションはそのまま残ります。

消したいときは MOD ページの **RESET** ボタン（CLOSE の隣）を使ってください。8 スロットと 4 つの LFO だけが既定値に戻り、メイン画面・プリセット・テーマには一切触れません。確認ダイアログが出ます。

### おすすめの組み合わせ

- **LFO1 (Sine, 1/4 sync) → S1 Low X, AMOUNT 40 %** — 低域の分割点が拍に合わせて上下し、ベースの重心が揺れます。
- **LFO2 (Rnd Trig, 1/16 sync) → S1 Rel Hi, AMOUNT 80 %** — 高域のリリースが不規則に伸び縮みし、テールがつっかえます。
- **Env Follow → S2 Mix, UNI ON, AMOUNT 60 %** — 音が大きいときだけ 2 段目が深くかかります。
- **Drift → S2 High X, AMOUNT 35 %** — 高域の分割点が当てもなく漂い、同じフレーズでも毎回わずかに違う響きになります。
- **LFO3 (Saw, 0.05 Hz) → LFO1 Rate, AMOUNT 50 %** — 20 秒かけて LFO1 が加速していきます。

## 7. RANDOM

ヘッダーの **RANDOM** ボタンで、メイン画面のノブとスライダーを引き直します。確認ダイアログは出ません（何度も回して当たりを探す使い方を想定しています）。

**一様乱数ではありません。** 全部を等確率で振ると、まず間違いなく使えない音になります。とくに致命的なのが帯域ゲインで、段数分だけ累乗されるため x128 で +8dB を引くと float が壊れる領域に飛びます。そこで以下の制約をかけています。

| 項目 | ルール |
|---|---|
| **GAIN** | 現在の OTT 段数から逆算した「1 段あたりの適正値」を中心に振る |
| **周波数・時間** | 対数一様。低い側と高い側が同じ確率で出る |
| **DEPTH / UP / DN** | 1 つの「強度」マクロから派生させ、バンド間の相関を保つ |
| **ATK / REL** | REL は必ず ATK より長い。高域ほど速く（象徴的なスイープが出る） |
| **クロスオーバー** | Stage1 と Stage2 を必ずずらす（本機の肝） |
| **OUT GAIN** | 段数に応じて自動で下げ、爆音事故を防ぐ |
| **PRE-DRIVE** | 55% の確率で ON。OFF のときは Drive/ODD/EVEN もゼロ |
| **STAGE 2** | 15% の確率で OFF になり、素直な 1 段だけの音も出る |

**触らないもの** — OTT 数、PHASE MODE、リミッター設定、カラーテーマ、MOD マトリクス。これらは「構造の選択」なので、あなたが決めた枠の中で RANDOM が性格を埋める形になります。段数を決めてから回すのが使い方です。

引いたあとはヘッダーのプリセット名が `RANDOM` に変わります。気に入ったら PRESET → SAVE で保存してください。

## 8. PRESET

### ブラウザ

左にカテゴリ、右にプリセット一覧。上部の検索欄で名前とカテゴリを絞り込めます。

- **ダブルクリック / Enter** — 読み込み
- **右クリック** — Load / Delete
- **SAVE** — 現在の全パラメータをユーザープリセットとして保存
- **INIT** — 全パラメータを既定値へ（テーマと MOD は維持）

**FACTORY** バッジが付いたものはプラグイン内蔵で、削除できません。ユーザープリセットは以下に保存されます。

```
%APPDATA%\MULTI-OTO\Presets\<カテゴリ>\<名前>.motopreset
```

プリセットを読み込むと **OTT COUNT も推奨値に切り替わります**（名前の末尾の `(xNN)` がその値です）。x128 のプリセットは CPU 負荷が高いので注意してください。

### ファクトリープリセット一覧

| カテゴリ | 内容 |
|---|---|
| **Basic** (6) | 一般的な OTT の用途。Classic OTT / Gentle Glue / Vocal Presence / Drum Punch / Bass Weight / Sub Guardian |

## 9. 実践レシピ

### A. 「まとも」に使う（ミックス補助）

- **COUNT**: 2 または 4
- **PRE-DRIVE**: OFF、または Drive 10 % / Even 20 % 程度
- **PHASE MODE**: ALIGN PHASE（DRY/WET を混ぜたときの中抜けを防ぐ）
- **STAGE 1**: DEPTH 相当（UP / DN）を 60〜80 %、TIME を 150 % 程度に遅く
- **STAGE 2**: OFF
- **MIX**: 20〜40 %（典型的なパラレル・コンプレッション）

出発点には `Classic OTT (x2)` か `Gentle Glue (x2)` を。

### B. 「壊す」（サウンドデザイン）

- **COUNT**: 64 または 128
- **PHASE MODE**: COLOR PHASE（128 個の未補正クロスオーバーで位相が数万度ねじれ、トランジェントが「ピューン」というレーザー音に伸びます）
- **PRE-DRIVE**: Drive 80〜100 % / Odd 100 %
- **STAGE 1**（潰す役）: UP / DN 100 %、TIME 15〜30 %
- **STAGE 2**（テクスチャ抽出役）: LOW の UP を 0 % にしてサブを守り、MID / HIGH を 100 %。REL H を速く、REL L を遅く
- **クロスオーバー**: Stage 1 と Stage 2 で大きくずらす（例: S1 = 88 / 2.5k、S2 = 350 / 6k）

出発点には `Pulveriser (x128)` か `Split Band Fracture (x32)` を。

### C. 金属的な共鳴を作る

LOW X と HIGH X を極端に近づけると（例: 400 Hz / 1.1 kHz）、狭いミッドバンドが強く共鳴します。これを 2 段でわずかにずらして重ねると（S2 = 630 / 1.5k）、共鳴が二重にかかります。`Metallic Resonator (x64)` がこの手法です。

## 10. トラブルシューティング

**Q. 音が出ない / 途中から無音になった**
v1.0.0 に、クリップ後に内部状態が壊れて復帰しなくなるバグがありました。**v1.1.0 で修正済み**です。それでも起きる場合は、OTT COUNT を一度切り替える（ノード状態がリセットされます）か、プラグインを再読み込みしてください。

**Q. ノブを回すとブツブツ鳴る**
v1.1.0 で全パラメータに 20 ms のスムージングを入れています。それでも段差が出る場合は、TIME を上げてエンベロープの追従を遅くしてください。

**Q. CPU 負荷が高い**
COUNT を下げてください。負荷はほぼ段数に比例します。x128 は x8 の 16 倍です。

**Q. Ableton 以外の DAW で動くか**
検証していません。Windows / AVX2 必須です。
